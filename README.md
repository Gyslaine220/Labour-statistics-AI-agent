# Labour-statistics-AI-agent

The Labour Statistics AI Agent is a Python-based project that aims to use artificial intelligence and data analysis to answer questions about labour statistics.

The project will combine labour-force data, Python-based statistical analysis, and AI agent capabilities to help users explore labour-market indicators such as employment, unemployment, labour force participation, and youth unemployment.

This project is being developed step by step as a practical learning project to build skills in Python, data science, machine learning, and artificial intelligence.
